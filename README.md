# Проектирование систем и продуктовая веб-разработка 2026 (Разработка Интернет Приложений)

### Тема: Расчитать объем потребляемой датацентром электроэнергии в зависимости от оборудования в нем. Услуги - виды устройств (серверы, коммутаторы, СХД и тд), заявка - расчет потреблямой мощности с учетом охлаждения для датацентра со списком оборудования

## Запуск

```shell
npm install
npm run dev
```

Приложение открывается на `http://localhost:3000`. Данные карточек берутся из mock-коллекции `src/modules/mock.ts`, бэкенд, БД и S3 не нужны. Фото и видео устройств из mock лежат в проекте в `public/datacenter-media/`. Если у устройства пустое поле фото или видео, показываются файлы по умолчанию из `public/`: `default-device.jpg` и `default-device.webm`.

## Страницы

Снизу на всех страницах панель навигации из 4 пунктов: «Лента», «Добавление», «Плитка», «Вход». Доступны только «Лента» и «Плитка».

### Плитка `/datacenter-devices`

- поле «Мощность от»: ползунок от 0 до 2000 Вт с шагом 50 Вт;
- кнопка «Показать»: показывает устройства с потребляемой мощностью не меньше выбранной (при 0 Вт показываются все);
- карточки в 2 столбца: фото, название, количество лайков, потребляемая мощность;
- клик по карточке открывает ленту с этого устройства.

### Лента `/datacenter-devices/reel/:id`

- вертикальное видео устройства на весь экран, проигрывается автоматически без звука;
- справа: количество лайков, потребляемая мощность (Вт) и тепловыделение (БТЕ/ч), кнопка «Дальше» — переход на `/datacenter-devices/reel/:id?next=true`, то есть на следующее устройство (после последнего снова первое);
- снизу: название и краткое описание, кнопка «Ещё»/«Свернуть» раскрывает описание целиком;
- без `id` (пункт «Лента» в навигации) открывается первое устройство.
